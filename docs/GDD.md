## 3. 科別與 KPI 精算

### 3.1 科別（開局由事件分派，升遷時重新隨機分派）

| 科別 | 類型 | 每格「實地檢查」的產出 |
|---|---|---|
| 勞動條件科 | 工時、工資、加班費 | 4 場 |
| 一般行業科 | 製造業 | 3 場 |
| 土木工程科 | 營造（道路、橋梁） | 3 處工地 |
| 建築工程科 | 營造（建築工地） | 3 處工地 |
| 危險機械設備科 | 起重機、鍋爐等設備 | 4 台 |
| 職業衛生科 | 作業環境、化學品 | 2 場 |

### 3.2 每月 KPI：8 格中需要 6 格，預留 2 格

| 科別 | KPI 項目 1 | KPI 項目 2 |
|---|---|---|
| 勞動條件科 | 一般勞動檢查 20 場（5 格） | 申訴案結案 1 件（1 格） |
| 一般行業科 | 職安檢查 15 場（5 格） | 申訴檢查 1 件（1 格） |
| 土木／建築科 | 工地檢查 15 處（5 格） | 宣導 1 場（1 格） |
| 危險機械設備科 | 設備檢查 20 台（5 格） | 竣工審查 1 件（1 格） |
| 職業衛生科 | 衛生檢查 10 場（5 格） | 健檢稽核 1 件（1 格） |

- 每一項都要達到 100% 才算「達標」。
- 只有國考公假、颱風停班、排定的訓練這類「官方原因」會讓 KPI 按比例調降；重災、同事丟鍋不會調降。
- **情緒負壓 ≥70 時，所有產出減半**（無條件捨去）。這時 6 格的工作量需要 12 格才做得完，等於這個月必定未達標，所以玩家必須先把負壓降下來。
- 職級越高，KPI 型態會改變：技正要審核報告；科長的 KPI 是全科總和；處長的 KPI 是全處指標，再加上議會備詢等。

| 先把 KPI 做完再偷懶 | 0.65 | **2.0%** | 6.3 |
| 每月固定先偷懶 1 格 | 1.64 | 20.6% | 7.8 |
| 每月固定先偷懶 2 格 | 3.47 | 78.9% | 10.8 |

## 4. 情緒負壓系統（新增）

| 項目 | 規則 |
|---|---|
| 範圍 | 0–100，開局 20 |
| 顯示 | 常駐量表；50 以上變黃，70 以上變紅並閃爍「效率減半」 |
| **≥70** | 工作產出 ×0.5 |
| **=100** | **BAD END「職災統計表上的一筆」** |
| 自然回復 | 每週 −1 |

**BAD END「職災統計表上的一筆」**
> 你查了五年別人的過勞，卻沒注意到自己。某天下午，你在工地圍籬外蹲下來，再也站不起來。醫師的診斷書寫著「重度憂鬱合併過勞」。三個月後，處裡的年度職災統計表多了一筆——承辦人是你的學弟。

| 主管臨時交辦、雇主拒檢 | +3 |

| 同事擺爛丟鍋 | +6 |

| 摸魚 | −8 | — |

### 4.3 黑暗紓壓（負壓大降，但有代價）

| 選項 | 負壓 | 代價 |

| 收下紅包 | −20 | 貪污值 +25 |

## 5. 國考規則

**通過率 = 基礎值 + 累積加成（上限 60%，不顯示給玩家）**

基礎值：**逐階往上考 10%，跨階考 5%**。

| 目前身分 | 考四等 | 考三等（地特三等、高考三級） | 薦任升官等考試 |
|---|---|---|---|
| 約聘 | 10%（逐階） | **5%（跨階）** | 不能報考 |
| 技佐（四等錄取） | — | 10%（逐階） | 10%（逐階） |

| 項目 | 規則 |
|---|---|
| 累積加成 | 每次偷懶看書 +1~3%，各類考試共用 |
| 上限 | 60% |
| 重置 | **只有考上才把累積加成歸零**；落榜時保留 |
| 強制參加 | 約聘每年都要考高考（7 月）和地特（12 月，自選三等或四等）；技佐則要考三等或升官等考試 |
| 晉升簡任官等訓練 | 不是考試。通過率＝60%＋每次「優」等 +10% |
| 轉正後 | 偷懶看書選項消失，只剩摸魚 |

**路線影響（已驗算）**

- 第 1 年考上三等，才有機會在 5 年內升到處長，這是 True 結局。
- 四等路線比較好考，但要再考一次三等或升官等考試，實際上大多停在技正或科長左右。
- 第 2 年以後才考上，最高約到科長或副處長。

## 8. 技術架構

- Vite + TypeScript，不用框架；GitHub Actions 部署到 Pages
- localStorage 存檔：每格自動存檔，另有 3 個手動存檔槽
- 所有內容都放在 `src/data/*.json`（資料驅動），核心邏輯寫成純函式，用 Vitest 測試；亂數可以指定種子
- UI 採「政府公文系統」風格：米白公文紙底色、朱紅印章點綴；KPI 用進度條、負壓用量表、月曆用格子；事件以公文彈窗呈現；手機版優先，支援深色模式

```
src/data/  ranks · divisions · kpi · actions · events · calendar · endings (.json)
src/ui/    screens/ · components/        scripts/simulate.ts      tests/
```
